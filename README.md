## What it is

A single-page interactive route guide for a full SoulSilver playthrough. Instead of dumping every move and item everywhere, it shows **only what matters at each point of the run** — the team, the TMs to grab, key items, purchases, and moves at the levels you actually get them.

## Four play modes

The guide ships with a mode switcher (top tabs, pick and it remembers):

- 🔄 **Trade Team** — the flagship six: Typhlosion · Gyarados · Alakazam · Heracross · Gengar · Lapras
- 🚫 **Zero-Trade** — no Union Room needed: Kadabra + Ampharos in place of the trade evolutions
- ⚡ **Speedrun** — any% glitchless route: Cyndaquil solo carry, Fire Blast, level-50 Magikarp→Gyarados
- 💀 **Nuzlocke** — one catch per area, fainted = dead, gifts and statics as freebies

Each mode swaps in its own team, banner, and per-phase route steps — collapsible phases with an expand/collapse-all toggle.

## What's inside

- **Route timeline** across 6 phases (New Bark → Violet → Azalea → Ecruteak → Olivine → Cianwood → Blackthorn → Elite Four)
- **Per-phase bundles**: what to Catch, Grab, Buy, which Moves matter, Gym counters, and the SAVE point
- **Full moveset tables** (Serebii-verified) with a TM-saver rule — don't waste Game Corner coins on moves you learn naturally
- **E4 counter strategy** for Will · Koga · Bruno · Karen · Lance
- **18 maps** (Johto, Kanto, caves, and route maps) embedded so they actually display
- **Durable-save protocol** — how to keep your run safe on an emulator
- **Trade setup** walkthrough (Union Room) for the Alakazam + Gengar line
